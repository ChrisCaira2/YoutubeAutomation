# Game Day Brain: channel kit

Everything to set up youtube.com/@GameDayBrain. Made 2026-11-09. Redraw the art any time with `cd backend && ../.venv/bin/python game_day_brain_art.py`.

## Files to upload

| File | Where it goes in YouTube Studio | Notes |
|---|---|---|
| `profile.png` (800 x 800) | Customization > Branding > Picture | The glowing brain, in the command-center look. Reads clearly down to comment size. |
| `profile-mascot.png` (800 x 800) | Same place, if you prefer it | The mascot fan tapping his temple: matches the videos and thumbnails. |
| `banner.png` (2560 x 1440) | Customization > Branding > Banner image | The name and tagline sit inside YouTube's safe area, so phones, TVs and computers all show every word. |
| `watermark.png` (150 x 150) | Customization > Branding > Video watermark | Choose "End of video" so it doesn't sit over the captions the whole time. |

## Upload defaults (Settings > Upload defaults)
The studio writes each video's description, sources and AI note itself, so leave the default description empty. Set these once:
- **Category:** Education. Sports puts you beside highlight channels; these videos are explainers.
- **Audience:** No, it's not made for kids.
- **License:** Standard YouTube License.
- **Comments:** On, held for review only if they look inappropriate.
- **Default tags:** game day brain, sports psychology, sports science, fan psychology

## Every upload
- **Altered or synthetic content:** answer Yes when YouTube asks during upload. The pictures are plainly drawn, so YouTube doesn't strictly require the label, but the model channel uses it and it protects the channel.
- Use the title, thumbnail, description and tags from the video's package in the hub.
